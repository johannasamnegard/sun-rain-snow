# Weather App

A blank HTML starter project powered by Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Recommended weather API

Use [Open-Meteo](https://open-meteo.com/). It is a good fit for this starter
because it requires no API key or account and supports direct requests from a
browser.

- [Weather forecast API documentation](https://open-meteo.com/en/docs)
- [City geocoding API documentation](https://open-meteo.com/en/docs/geocoding-api)

Use the geocoding API to convert a city name into latitude and longitude, then
pass those coordinates to the forecast API. Review Open-Meteo's current usage
limits and attribution requirements before publishing the app.
